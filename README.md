## 🎯 What Is This?

The PixelProTech Typing Machine is a **free, browser-based typing trainer** designed specifically for South Africans preparing for data capture jobs, office administration roles, and any position that requires keyboard competency.

Most employers test typing speed at interviews. This tool gets you ready — for free.

## ⚡ Features

### 🎮 7 Training Modes
| Mode | What You Practice |
|------|-------------------|
| **Beginner** | Simple everyday sentences — build confidence |
| **Office** | Professional business language and correspondence |
| **Data Capture** | ID numbers, invoices, employee records, SA formats |
| **Coding** | Functions, queries, and technical syntax |
| **CV Typing** | Career-specific professional language |
| **Gov Forms** | Home Affairs, SARS, and municipal document formats |
| **Speed Demon** | Maximum velocity — push your limits |

### ⏱️ Timer Options
- 15 seconds — quick burst training
- 30 seconds — standard session
- 60 seconds — endurance building
- 120 seconds — full stamina test
- ∞ Infinite — practice without pressure

### 📊 Live Stats
- **WPM** — Words Per Minute (live)
- **Accuracy %** — Real-time precision tracking
- **Characters typed** — Total character count
- **Mistakes** — Error tracking per session

### 🎹 Keyboard Heatmap
Visual display of which keys you press correctly (green) and which keys trip you up (red). Identifies your weak fingers instantly.

### 📈 WPM Performance Graph
Live SVG chart showing your speed trend across the session. Watch your WPM climb in real time.

## 🚀 Deployment

Single HTML file — zero dependencies. Works offline.

**GitHub Pages:**
1. Upload `index.html` to repo root
2. Settings → Pages → Deploy from branch → main → / (root)
3. Live at `https://[username].github.io/[repo-name]/`

**Local:** Open `index.html` in any browser. Done.
